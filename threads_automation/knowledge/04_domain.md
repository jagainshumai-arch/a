# 04 専門知識（ドメインナレッジ）

## AIツール知識

### ChatGPT
- OpenAI提供、最も普及しているAI
- GPT-4o: 最新モデル、画像・音声対応
- GPTs: カスタムチャットボット作成機能
- メモリ機能: 過去のやり取りを記憶
- 月額$20（Plus）、無料版あり
- **投稿ネタとしての強み**: 知名度No.1、初心者の関心が最も高い

### Claude
- Anthropic提供
- 長文の自然な日本語が得意
- 200Kトークンの大量コンテキスト
- **投稿ネタとしての強み**: 「ChatGPTより○○が得意」の比較系が伸びる

### Gemini
- Google提供
- 長文出力に強い、トークン制限が緩い
- Google Workspaceとの連携
- **投稿ネタとしての強み**: 「無料で使える」点が初心者に刺さる

### その他注目ツール
- Perplexity: AI検索エンジン
- Midjourney / DALL-E: 画像生成
- Canva AI: デザイン自動生成
- Dify / Make: AIワークフロー自動化
- Cursor / Windsurf: AIコーディング
