## 共通する勝ちの要素

- **1行目に「具体的な数字」または「断定」が必ず入る**（「肌年齢-5歳」「月5万円」「億事業作るのは超簡単」）
- **Before→Afterの落差を数字で見せる**（「3時間→5分」「3ヶ月後にマイナス5歳」）
- **"特別なものは要らなかった"系の逆説**で参入ハードルを下げる（「特別なスキルは要らなかった」）
- **再現できる手順 or 構造の提示**（「やったこと3つ」と番号付きリスト）
- **未来予測・断言で権威性**（「2026年から〜がスタンダードになる」）— 言い切る人ほど伸びる
- **短文・改行多め**で視認性が高い（1文1行、塊で読ませない）
- **固有名詞でフック**（Claude code / Threads 等）— 「知ってる人向け」の信頼感を出す

## 抽出した型（再現テンプレート）

### 型A: 数字×手順型（最も安定）
**使う場面**: ノウハウ・時短・効率化の共有
**1行目のテンプレ**: 「〔固有名詞〕で〔具体的な成果を数字で〕。実際にやったこと〔N〕つ👇」
**構成**: 1行目で結果提示 → 番号付き手順3つ → 「たったこれだけで〔期間〕後に〔成果〕」で締め

### 型B: 逆説×Before/After型
**使う場面**: 収益・成長の体験談
**1行目のテンプレ**: 「〔成果〕するのに、〔常識的に必要そうなもの〕は要らなかった。」
**構成**: 1行目で常識を否定 → 「必要だったのは〔意外な1つ〕だけ」→ 時系列の成果（3ヶ月目で〜、半年で〜）→ 「〔X〕じゃなくて〔Y〕が大事」で教訓化

### 型C: 断言×未来予測型（権威性・拡散狙い）
**使う場面**: 業界の構造変化・ポジショントーク
**1行目のテンプレ**: 「〔固有名詞・新技術〕がある今、〔常識的に難しいこと〕は超簡単。」
**構成**: 1行目で断言 → 仕組みを2〜3文で要約（誰でも追える粒度）→ 「〔年〕から〔新常識〕がスタンダードになる」で未来を言い切る
**注意**: 断言は「自分の見立て」として語る。他人の結果を保証する表現はNG（`07_ng-rules.md`）

## 数字・固有名詞の使われ方

- **数字は"変化量"か"期間"で使うと効く**（-5歳 / 月5万 / 3ヶ月 / 3つ）。漠然とした大きい数字より、読者が自分ごと化できるスケールが強い
- **固有名詞は1行目に1つ**（Claude code, Threads, ChatGPT）。複数並べるのは本文中盤で（「Youtube・インスタ・X・Threads全て同じ要領」のように"網羅"を見せる時）
- 金額は生々しいほど刺さるが、景表法ライン（保証・断定）を越えないこと

## このニッチで避けるべきこと

- **ハッシュタグ**（収集データのスキンケア投稿は#付きだが、Threadsでは逆効果。タグは付けない → `07_ng-rules.md`）
- 1行目に固有名詞も数字も無い（フック不在で離脱）
- 手順や構造が無く「すごい」だけで終わる（再現性ゼロ＝保存されない）
- 「確実に」「誰でも」「リスクゼロ」等の保証表現（景表法違反）
