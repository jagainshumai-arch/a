# 05 書き方のルール

## 7つの黄金ルール（リーチ爆発の法則）

### ルール1: 質問形式で巻き込む
- 投稿の中に読者への問いかけを入れる
- 「みんなはどう使ってる？」「どっち派？」「欲しい人はスタンプ押して」
- 問いかけ → コメント増加 → アルゴリズム評価UP → リーチ爆発

### ルール2: 投稿タイミングを最適化
- **朝 7:00〜9:00**（通勤中にサクッと読める）
- **昼 12:00〜13:00**（昼休みの関心が高い）
- **夜 20:00〜22:00**（ゆっくり読める時間帯）
- 投稿直後の反応速度がアルゴリズムに影響大

### ルール3: 1行目で止める
- スクロールを止めさせる1行目が全て
- **固有名詞**（ChatGPT/Claude/Perplexity/Gemini）+ **数字**を必ず入れる
- 意外性・ギャップ・具体的変化を1行で表現
- **権威性**（「月○万」「○人が購入」）も1行目に効く

### ルール4: 行動喚起（CTA）を入れる
- 「スタンプ押して」「コメントで教えて」「欲しい人いる？」
- **商品誘導時**: 「リンクはストーリーズ」「bio見て」
- 最後の1行で必ず読者にアクションを求める

### ルール5: 投稿構造を最適化する
- **冒頭**: 権威性 or 意外な事実で注目を集める
- **本文**: 箇条書き・短文で読みやすく
- **結論**: アクションを促す一文で締める
- 1文ごとに改行。空行で区切る

### ルール6: ニッチに絞って毎日投稿
- AI活用×仕組み化×収益化に特化
- 1日2〜3投稿を継続
- 独自の視点を加えて価値ある情報を提供し続ける

### ルール7: データで改善し続ける
- 伸びた投稿のパターンを分析→再現
- 伸びなかった投稿の失敗要因を特定
- 定期的に勝ち型テンプレートを更新

## 投稿のモード切り替え

### 通常モード（日常投稿 — 8割）
価値提供を中心に、権威性と信頼を積み上げる。

### ローンチモード（商品販売時 — 2割）
14日間のプロダクトローンチフォーミュラに従う（13_launch_strategy.md参照）。

## 1行目（フック）パターン集

| パターン | 例 |
|---------|-----|
| **権威性・実績** | 「今月もう売上○万超えた。GWはほぼ作業してないのに」 |
| **発見・驚き** | 「ChatGPTに"逆に反論して"と指示したら、出力の質が別次元になった」 |
| **Before/After** | 「Claudeに任せたら、3時間の作業が5分で終わった」 |
| **比較・実験** | 「同じ指示をChatGPTとClaudeに出した。差がエグかった」 |
| **知らないと損** | 「ChatGPTの"カスタム指示"、設定してない人が9割らしい」 |
| **逆説・意外** | 「AIを毎日使ってる人ほど、実は損してる使い方をしてる」 |
| **問題提起** | 「フォロワー増やしても売上出ない人、共通点がある」 |
| **制作発表** | 「300人以上が"欲しい"って言ってくれたから、作り始めました」 |
| **緊急性** | 「先着○名で締め切ります。残り○部」 |

## 投稿のトーン

### やること
- **等身大で語る**：「自分はこうだった」「気づいたんだけど」
- **驚きを共有する**：「これマジか」「知らなかった」
- **読者を巻き込む**：「欲しい人いる？」「試してみて」
- **体験ベース**：「○○してみたら→こうなった」
- **断言する**：「これは使った方がいい」「戻れなくなる」
- **収益の話はリアルに**：「ぶっちゃけ月○万いけた」
- **仕組み化の魅力**：「寝てる間に売上出てた」

### やらないこと
- 「確実に稼げます」等の断定的な保証（景表法違反）
- 上司・部下・社内等のサラリーマン用語
- 先生・専門家ポジションで上から語る
- 「あなたもやるべき」と押し付ける

## 本文の構成ルール

### 基本パターン：本文で引き→リプ欄で本題

> **最重要: 本文で完結させない。リプ欄にタップさせる構造にする。**
> タップ経済 = 本文タップ（1回目）→ リプ欄タップ（2回目）→ コメント（3回目）

```
【本文（300〜500文字）】
1行目: 権威性 or 発見（固有名詞+数字のフック）
空行
背景: なぜそうなったか / きっかけ 2〜3行
空行
核心のチラ見せ: 結果は○○だった（詳細はまだ書かない）
空行
リプ欄誘導: 「具体的な方法はリプ欄に↓」「使ったプロンプトはリプ欄↓」

【リプライ欄（200〜400文字）】
具体的な手順 / プロンプト / 裏ワザ（本文で出し惜しみした本題）
空行
CTA: 「欲しい人はスタンプ」「試してみて」「みんなはどう？」
```

### ローンチ時の構造：複数枚投稿

```
【1枚目】
権威性 or フック（インパクトのある1行目）

【2枚目】
フォロワーの悩みリスト or 理想の未来

【3枚目（必要に応じて）】
解決策の提示 or 商品案内 or CTA
```

### リプ欄誘導フレーズ集
- 「使ったプロンプトをそのままリプ欄に貼った↓」
- 「具体的なやり方をリプ欄にまとめた↓」
- 「他にも3つ見つけたのでリプ欄に書いた↓」
- 「設定方法をリプ欄に貼った↓」
- 「コピペで使えるテンプレをリプ欄に置いた↓」

### 文字数
- **本文: 300〜500文字**（気になる内容を詰める）
- **リプライ欄: 200〜400文字**（最も有益な情報をここに）

### 改行ルール
- 1文ごとに改行
- 重要ポイントの前に空行
- 箇条書き（・や①②③）を使う

### 語調
- 自然な口語体。話しかけるように
- 断言する（「〜かも」→「〜だった」「〜変わった」）
- 「僕」「自分」を主語に。読者に「あなた」「みんな」で語りかける

## ハッシュタグ：使わない

> **重要: ハッシュタグ（#）は一切使わない。**
> Threadsではタグをつけた瞬間にインプレッションが激減するという実データあり。
