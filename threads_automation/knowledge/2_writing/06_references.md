# 06 参考投稿（リファレンス）

## 投稿の大原則
- **売上・収益の話はしない**
- **AI活用の気づき・知見・効率化ノウハウだけ**
- **1行目で「読みたい」と思わせる**
- **ハッシュタグ（#）は使わない**
- **本文は「続きが気になる」で終わらせる → リプライ欄で本題を書く**
- **リプライ欄にこそ一番有益な情報を入れる（タップ数を稼ぐ）**

## タップ経済を最大化する構造

```
【本文（300〜500文字）】
1行目: 固有名詞+数字のフック（タップ1回目を誘導）
↓
途中で「核心」をチラ見せ（気になるが完結しない）
↓
最後: 「具体的な方法はリプ欄に↓」「使ったプロンプトはリプ欄↓」

【リプライ欄（200〜400文字）】
本題の具体的な手順・プロンプト・裏ワザ（タップ2回目）
↓
最後にCTA:「みんなはどう使ってる？」（コメント誘導）
```

> **なぜこの構造がバズるのか**
> 本文タップ（1回目）→ リプライ欄タップ（2回目）→ コメント（3回目）
> アルゴリズムが「この投稿は反応が多い」と判断 → リーチ爆発

## 高パフォーマンス投稿の型（全てリプライ欄付き）

### 型1: 発見・驚き型
**本文:**
```
ChatGPTに「逆に反論して」と追加したら、出力の質が別次元になった。

いつも「〇〇について教えて」で終わってた。
返ってくるのは無難な正論ばかり。

試しに「それに反論して」と追加してみた。

すると、自分では思いつかない視点がバンバン出てくる。
レポートのアイデア出しが30分→5分に。

AIは"1往復"で終わらせるともったいない。

他にも使える「追加の一言」を3つ見つけたので、リプ欄に書いた↓
```
**リプライ欄:**
```
使える「追加の一言」3つ。

① 「もっと具体的に」
→ 抽象的な回答が消えて、すぐ使える内容に変わる

② 「別の角度から」
→ 自分では思いつかない切り口が出てくる

③ 「それを初心者に説明するなら？」
→ 難しい内容が一気にわかりやすくなる

この3つを覚えてから、ChatGPTの使い方が根本的に変わった。

みんなはどんな「追加の一言」を使ってる？
```

### 型2: Before/After型
**本文:**
```
Claudeにゼミの記録を任せてから、ゼミ後の2時間が消えた。

前はゼミ中にメモして、終わったら清書して、先生に提出して…
毎回2時間。週2回ゼミだから週4時間。

今はClaudeに音声テキストを放り込んで1つの指示を出すだけ。
3分で終わる。

週4時間が週6分になった計算。

使ったプロンプトをそのままリプ欄に貼った↓
```
**リプライ欄:**
```
使ってるプロンプトがこれ。

「以下のゼミの音声テキストを整理して。
・要約（3行以内）
・決定事項（箇条書き）
・次のアクション（担当者つき）
・未解決の議題
の4つに分けて。敬語不要、簡潔に。」

これをClaudeに投げるだけ。

ポイントは「敬語不要、簡潔に」をつけること。
これがないと堅い文章になって読みづらい。

ゼミ以外にも、グループワークのメモ・サークルの議事録でも使えるから試してみて。
```

### 型3: 比較・実験型
**本文:**
```
同じプロンプトをChatGPT・Claude・Geminiに投げてみた。差がエグかった。

指示:「サークルの新歓で使う自己紹介文を書いて」

ChatGPT → しっかりした文章。でも堅い。テンプレ感。
Claude → カジュアル寄り。「この人と話したい」と思える文面。
Gemini → Google感が出る。実用的だけど個性がない。

3つ使い分けたら仕事の質が明らかに上がった。

どの場面でどれを使うか、自分なりの使い分けルールをリプ欄にまとめた↓
```
**リプライ欄:**
```
自分の使い分けルール。

・レポート・文章を書くとき → Claude
　人間っぽい文章が一番うまい。レポート、エントリーシート、SNS投稿。

・コードを書くとき → ChatGPT
　コーディング精度はまだChatGPTが一歩リード。

・調べものをするとき → Perplexity
　出典付きで回答してくれるから信頼できる。

・メール返信 → Gemini
　Gmail連携が最強。「このメールに返信して」が一言でできる。

・データ分析・グラフ作成 → ChatGPT
　CSV投げるだけでグラフまで出してくれる。プレゼン資料に最高。

全部無料で使えるから、まず1週間試してみて。
あなたはどう使い分けてる？
```

### 型4: 知らないと損型
**本文:**
```
ChatGPTの"カスタム指示"、設定してない人が9割らしい。

これ設定するだけで、毎回「です・ます調で」「簡潔に」と指示しなくて済む。

自分の場合は4行書いただけ。
たったそれだけで、毎日のAI作業が体感2倍速くなった。

しかもChatGPT以外に、ClaudeにもGeminiにも同じ機能がある。
全部設定したら世界が変わる。

設定場所と、自分が書いてる内容をそのままリプ欄に貼った↓
```
**リプライ欄:**
```
まずChatGPTの設定方法。

設定 → カスタム指示 → 以下を入力↓

「回答は300文字以内。
箇条書き推奨。
敬語不要。
具体例を必ず1つ入れる。」

たったこれだけ。

Claudeの場合:
プロジェクト → カスタムインストラクション に同じ内容を入力。

Geminiの場合:
設定 → Gems → 新しいGemを作成 → 指示に入力。

3つ全部やると、どのAIを使っても自分好みの回答が返ってくる。

知らなかった人、今すぐやってみて。
```

### 型5: 逆説・意外型
**本文:**
```
AIを毎日使ってる人ほど、実は損してる使い方をしてる。

99%の人が「質問→回答」の1往復で終わってる。

でもAIの本当の力は「深掘り」にある。

1往復で終わる人と、5往復する人で、出力の質が5倍変わる。

嘘だと思うなら、次にChatGPT使うとき試してほしいことがある。

やることは3つだけ。リプ欄に書いた↓
```
**リプライ欄:**
```
AI深掘りの3ステップ。

① まず普通に質問する
② 返ってきた答えに「もっと具体的に」
③ さらに「それに反論して」

これだけ。

②で抽象論が消えて具体的な内容になる。
③で自分では思いつかない視点が出てくる。

さらに上級者は
④「この内容を初心者に説明するなら？」
⑤「表にまとめて」

この5往復をやるだけで、ChatGPTもClaudeも出力が完全に変わる。

「1往復で使ってた…」って人、今日から変えてみて。
```

### 型6: 質問型（巻き込み重視）
**本文:**
```
Geminiのディープリサーチ、使ったことある人どれくらいいる？

正直これ、ChatGPTにもClaudeにもない最強機能だと思ってる。

「○○について調べて」と言うだけで
60以上のサイトを自動で巡回→出典付きレポートを作ってくれる。

調べものに3時間かけてた自分がバカみたいになった。

しかも無料で使える。

使い方と「こう指示すると精度が上がる」コツをリプ欄に書いた↓
```
**リプライ欄:**
```
Geminiディープリサーチの使い方。

① gemini.google.com を開く
② 「○○について詳しく調査して」と入力
③ リサーチプランが表示されるので「開始」をタップ
④ 数分待つと出典付きレポートが完成

精度を上げるコツ:
・「日本語の情報源を優先して」をつける
・「2025年以降の情報に絞って」と期間指定する
・「比較表を含めて」で構造化された出力になる

ダブルチェック機能も忘れずに。
回答の下に出る「G」マークを押すと、嘘がないか自動検証してくれる。

ChatGPTにはこの機能がないから、調べものはGemini一択。

みんなは調べもの、何使ってる？
```

### 型7: 小技・裏ワザ型
**本文:**
```
Claudeに「XMLタグで囲んで指示する」だけで、出力の精度が劇的に変わる。

普通の人: 「レポートを書いて」
自分: 同じ指示なのに、出力の質が全然違う。

違いは「指示の構造化」にある。

ChatGPTでも使えるけど、Claudeだと効果が特に大きい。

やり方は超簡単。リプ欄のテンプレをコピペするだけ↓
```
**リプライ欄:**
```
使ってるテンプレがこれ。

<role>あなたはレポート作成の専門家です</role>

<context>
大学のゼミで「AIが教育に与える影響」について発表する。
聞き手はゼミの教授と学生15人。
</context>

<task>
発表のアウトラインを5パターン出してください。
各案にメリット・デメリットをつけて。
</task>

<rules>
・1パターン3セクション以内
・専門用語は使わない
・データや具体例を必ず入れる
</rules>

これをClaudeに投げるだけ。

普通に「発表のアウトライン考えて」と言うより、
出力の質が体感3倍は変わる。

コピペして使ってみて。
```
