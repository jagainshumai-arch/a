# 16 Threadsバズ投稿テンプレート集（実データ調査ベース）

> Threadsの「おすすめ（伸びている推奨投稿）」に上がる投稿を横断調査し、
> 再現可能な型に落とした穴埋めテンプレート集。`06_references.md`（具体例7型）の
> 「設計図」として使う。writer/autopost はここのフック型・締め型を優先して組み立てる。
>
> ※ Threads APIは他者投稿を検索できないため、本ファイルは公開されている
>   バズ分析（複数ソース／2025–2026）の横断調査から作成。生の実測データが
>   貯まったら `5_buzz/patterns.md`・`themes.md` が上書き的に優先される。

## なぜこの型が効くのか（アルゴリズムの前提）

Threadsのおすすめ表示は、投稿を **4つの評価ステージ** で選抜する:

```
Stage1 フォロワーの一部に表示   ← 投稿直後の「初速」、特に返信が評価される
Stage2 フォロワー全体に表示     ← Stage1を突破すると拡大
Stage3 おすすめ（非フォロワー） ← ここに乗るとリーチ爆発
Stage4 Instagram等へ波及
```

- **返信率が最重要指標**（目安0.3%以上）。フォロワー数より **エンゲージメント率**で決まる
  → フォロワー100人でも返信率が高ければ、1万人の低返信投稿より広く配信される
- **滞在時間（読ませる長さ）と保存数**も効く。保存されやすい＝「価値がある」と判定される
- フィードは展開前の **最初の2行**しか見えない → 1行目・2行目で掴めなければ以降は読まれない

**結論：全テンプレは「初速の返信」と「滞在時間」を取りにいく形になっている。**
（本文で引き→リプ欄で本題→締めで質問、の3タップ構造。詳細は `05_writing.md`）

## 1行目フックの型（穴埋めテンプレ）

> 1行目に全力。**固有名詞（ChatGPT/Claude/Gemini/Python等）＋数字＋感情**を必ず入れる。

| 型 | 穴埋めテンプレ | このアカウントでの記入例 |
|----|--------------|----------------------|
| 数字・実績型 | `〔期間〕で〔成果を数字〕にした〔方法/話〕` | 「3ヶ月でThreadsの閲覧を月1万→30万にした話」 |
| 逆説・意外型 | `〔皆がやってること〕してる人ほど、実は〔損/逆効果〕` | 「ChatGPTを毎日使ってる人ほど、実は稼げない使い方をしてる」 |
| 問題提起型 | `〔対象〕で〔悩み〕な人に知ってほしい話` | 「AIで稼ぎたいのに何から始めるか分からない人に伝えたい」 |
| 知らないと損型 | `〔機能/裏ワザ〕、設定してない人が〔割合〕らしい` | 「ChatGPTのカスタム指示、設定してない人が9割らしい」 |
| 共感・失敗談型 | `〔過去の自分〕だった頃に言いたい〔教訓〕` | 「AI副業で消耗してた頃の自分に言いたい3つのこと」 |
| 意志表明型 | `今日から〔挑戦〕を全部公開していきます` | 「今日からClaudeで自動収益を作る過程を全部公開していく」 |
| Before/After型 | `〔ツール〕に〔作業〕を任せたら、〔時間/労力〕が消えた` | 「Claudeに投稿作成を任せたら、3時間の作業が5分で終わった」 |

**共通ルール:** 断定で言い切る／数字を入れる／1行で完結させない（続きを読ませる）。

## 拡散しやすいフォーマット（本文の骨格）

### A. リスト・ランキング型（保存されやすい＝最強）
```
〔テーマ〕で本当に効くの、この〔N〕個だけ。

（本文では見出しだけチラ見せ or 数だけ予告）
全部の中身と使い方はリプ欄に書いた↓
```
- 例:「AIで時短できるツール、正直この5個だけ覚えればいい」
- 「○○の習慣10選」「やめるべき○○ TOP7」など、数字＋列挙は保存を呼ぶ

### B. 手順・ノウハウ型（役立つ系＝拡散＋フォロー両取り）
```
〔成果〕するためにやったこと、〔N〕ステップで書く。

具体的な手順・プロンプト・ツール名はリプ欄↓
```
- 抽象にしない。**具体的な数字・手順・ツール名・プロンプト**を必ず入れる

### C. 実験・比較型（滞在時間を稼ぐ）
```
同じ〔条件〕を〔A〕と〔B〕と〔C〕で試した。差が〔驚き〕だった。

〔各結果を1行ずつ〕
使い分けルールはリプ欄にまとめた↓
```

### D. 逆説・気づき型（コメントを呼ぶ）
```
〔常識〕は、実は〔逆の主張〕。

〔理由を短く〕
〔具体策の入口だけ〕→ リプ欄に続き↓
```

## 締めの型（返信＝初速を取りにいく）

本文の締めは必ず「リプ欄へ誘導」、リプ欄の締めは必ず「質問（返信誘発）」。

- 「みんなは〔テーマ〕、どうしてる？」
- 「〔選択肢A〕派？〔選択肢B〕派？」
- 「他にいい方法あったら教えて」
- 「〔過去の自分〕だった人、今日から変えてみて」
- 「知らなかった人、試したら感想ちょうだい」

> 二択・自分ごと化できる質問ほど返信が付く。抽象的な「どう思う？」は弱い。

## 文字数・改行の型

- **短型**: 100〜150字（断言・気づき系。テンポで読ませる）
- **標準型**: 本文300〜500字＋リプ欄200〜400字（ノウハウ系）
- **改行は3〜5行ごと**に空行。1行1メッセージで、スマホで「詰まって見えない」状態にする
- 最初の2行に一番おいしい引きを置く（展開前で勝負が決まる）

## Threads特有のNG（テンプレに混ぜない）

- **ハッシュタグ（#）を付けない** … Threadsではインプレッションが下がる（Xと逆）
- **本文に外部リンクを直貼りしない** … 外部誘導はリーチが落ちる。リンクはプロフィール/リプ欄で
- **1行目で答えを全部言わない** … 完結させると滞在時間もタップも取れない
- **AI感の出る定型** … 「〜だと思いませんか？」「いかがでしたか？」「〜と言えるでしょう」
- **景表法NG** … 「確実に稼げる」「誰でも月○万」「リスクゼロ」「100%再現」（`07_ng-rules.md`）
  ※自分の実績を語るのはOK、他人への結果保証はNG
