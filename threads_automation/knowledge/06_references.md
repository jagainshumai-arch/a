# 06 参考投稿（リファレンス）

## 高パフォーマンス投稿の型

### 型1: 数字+成果報告
```
ChatGPTに毎朝5分だけ指示を出す生活を3ヶ月続けた結果。

・ブログ記事: 月0本→月30本
・Threads投稿: 1時間→10分で完成
・副業収入: 0円→月12万円

やったことはプロンプトを3つ覚えただけ。

特別なスキルは何もいらなかった。

#ChatGPT #AI副業
```
**伸びる理由**: 1行目に固有名詞(ChatGPT)+数字(5分, 3ヶ月)、Before/Afterが明確

### 型2: 比較・ランキング
```
Claude 3.5とChatGPT-4o、1000文字のメルマガを書かせた結果。

ChatGPT: 構成は完璧。でも文体が硬い。
Claude: 構成は少し甘い。でも「人が書いた感」がすごい。

結論→1行目のフックはChatGPT、本文はClaudeで書かせるのが最強。

これだけで開封率が1.5倍になった。

#Claude #ChatGPT #AI活用
```
**伸びる理由**: 2つの固有名詞の比較、具体的な使い分け、数字(1.5倍)

### 型3: 失敗→学び
```
AI副業を始めて最初の3ヶ月、収益ゼロだった。

原因は「AIに丸投げ」してたから。

ChatGPTが書いた文章をそのままThreadsに貼ってた。
反応ゼロ。フォロワー増えない。

変えたのは1つだけ。
「1行目に具体的な数字を入れる」

これだけで表示回数が10倍になった。

#AI副業 #Threads運用
```
**伸びる理由**: 失敗への共感→具体的な解決策1つ→数字で変化を証明

### 型4: リスト型（○選）
```
ChatGPT無料版だけで月5万稼ぐ方法3選。

①AI記事ライティング
→1記事3000文字を30分で納品。単価3000円×月20本。

②プロンプト販売
→Brain/noteで1つ980円。月50部売れれば約5万。

③SNS運用代行
→投稿文をAIで量産。月3アカウントで5万。

全部やらなくていい。1つだけ選んで3ヶ月続ける。

#ChatGPT #副業 #AI活用
```
**伸びる理由**: 1行目に「無料版だけ」「月5万」、具体的な金額と手順

### 型5: 逆説・意外性
```
ChatGPTを毎日使ってる人ほど損してる事実。

99%の人が「質問→回答」の1往復で終わってる。

でも本当に使える人は「深掘り」してる。

「もっと具体的に」「別の角度から」「反論して」

この3つの追加指示だけで、出力の質が5倍変わる。

1往復で終わるのは、もったいなさすぎる。

#ChatGPT #プロンプト #AI活用
```
**伸びる理由**: 「使ってる人ほど損」の逆説、すぐ実践できる3つの具体指示
