# 06 参考投稿（リファレンス）

## 投稿の大原則
- **売上・収益の話はしない**
- **AI活用の気づき・知見・効率化ノウハウだけ**
- **1行目で「読みたい」と思わせる**

## 高パフォーマンス投稿の型

### 型1: 発見・驚き型
```
ChatGPTに「逆に反論して」と追加したら、出力の質が別次元になった。

いつも「〇〇について教えて」で終わってた。
返ってくるのは無難な正論ばかり。

試しに「それに反論して」と追加してみた。

すると、自分では思いつかない視点がバンバン出てくる。
企画書のアイデア出しが30分→5分に。

AIは"対話"させた方が圧倒的に使える。

#ChatGPT #AI活用 #プロンプト
```
**なぜ伸びるか**: 1行目に固有名詞+意外性、すぐ真似できる具体的テクニック

### 型2: Before/After型（時間の変化）
```
Claudeに議事録を任せてから、会議後の2時間が消えた。

前は会議中にメモして、終わったら清書して、上司に確認して…
毎回2時間。週3回会議だから週6時間。

今はClaudeに音声テキストを放り込んで
「要約・決定事項・次のアクション」で整理してと指示するだけ。

3分で終わる。

週6時間が週9分になった計算。

#Claude #作業効率化 #AI時短
```
**なぜ伸びるか**: Before/Afterが明確（2時間→3分）、読者が自分の状況に重ねられる

### 型3: 比較・実験型
```
同じプロンプトをChatGPTとClaudeに投げてみた。差がすごい。

指示:「新入社員向けの自己紹介メールを書いて」

ChatGPT → 完璧なビジネスメール。でも堅い。テンプレ感。
Claude → 少しカジュアル。でも「この人と話したい」と思える文面。

用途で使い分けるのが正解。
フォーマルな書類はChatGPT。
人に読ませる文章はClaude。

#ChatGPT #Claude #AI活用
```
**なぜ伸びるか**: 2つの固有名詞、読者が気になる比較、結論が明快

### 型4: 知らないと損型
```
ChatGPTの"カスタム指示"、設定してない人が9割。

これ設定するだけで、毎回「です・ます調で」「簡潔に」と指示しなくて済む。

自分の場合はこう書いてる↓
「回答は300文字以内。箇条書き推奨。敬語不要。」

たったこれだけで、毎日のAI作業が体感2倍速くなった。

設定場所: ChatGPT→設定→カスタム指示

知らなかった人、今すぐやってみて。

#ChatGPT #プロンプト #AI活用
```
**なぜ伸びるか**: 「9割が知らない」で興味喚起、即実践できる、設定場所まで書いてある

### 型5: 逆説・意外性型
```
AIを毎日使ってる人ほど、実は損してる使い方をしてる。

99%の人が「質問→回答」の1往復で終わってる。

でも本当に使える人は「深掘り」してる。

「もっと具体的に」
「別の角度から」
「それに反論して」

この3つの追加指示だけで、出力の質が5倍変わる。

1往復で終わるのは、もったいなさすぎる。

#ChatGPT #プロンプト #AI活用
```
**なぜ伸びるか**: 「使ってる人ほど損」の逆説、3つの具体指示がすぐ真似できる

### 型6: 日常の気づき型
```
Geminiに「今日の献立考えて」と頼んだら、地味に生活が変わった。

冷蔵庫の中身を伝えたら、3品の献立を15秒で提案してくれた。
しかも栄養バランスまで考えてくれてる。

毎日の「今日何作ろう…」が消えた。

AIって仕事だけじゃなくて、生活のストレスも減らせる。

これに気づいてから、毎日何かしら聞いてる。

#Gemini #AI活用 #AI時短
```
**なぜ伸びるか**: 日常の共感ポイント、「地味に生活が変わった」の等身大感

### 型7: 小技・裏ワザ型
```
ChatGPTに「小学生でもわかるように説明して」と付けるだけで、出力が劇的に変わる。

難しい企画書もAIの回答もそのままじゃ使えないことが多い。

でもこの一言を足すと
・余計な専門用語が消える
・構成がシンプルになる
・要点が3つくらいに絞られる

社内プレゼンの資料作りにこれ使ってから、上司に「わかりやすくなった」って言われた。

#ChatGPT #プロンプト #作業効率化
```
**なぜ伸びるか**: すぐ使える1フレーズ、具体的な変化が3つ、社内での成果エピソード
