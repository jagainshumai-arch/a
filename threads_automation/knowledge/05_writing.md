# 05 書き方のルール

## 最重要原則：タップ経済

> Threadsがバズるかどうかは**タップ数**と**プロフィールアクセス数**で決まる。
> タップしたくなる投稿を作ることが全て。
> **1行目で全てが決まる。**

## 1行目（フック）のルール

### 必須要素：固有名詞 + 数字（金額以外）
- ❌「AIって便利ですよね」
- ✅「ChatGPTの"深掘り指示"を覚えた日から、出力の質が5倍変わった」
- ❌「最近AIツール使ってます」
- ✅「Claude 3.5に乗り換えて3日。もうChatGPTに戻れない理由がある」
- ❌「作業が早くなりました」
- ✅「Perplexityに変えたら調べものが1日3時間→15分になった」

### 1行目パターン集（気づき・知見特化）
| パターン | 例 |
|---------|-----|
| **発見・驚き** | 「ChatGPTに"逆に反論して"と指示したら、出力の質が別次元になった」 |
| **Before/After（時間）** | 「Claudeに議事録を任せたら、2時間の作業が3分で終わった」 |
| **比較・実験** | 「同じ指示をChatGPTとClaudeに出した。差がエグかった」 |
| **知らないと損** | 「ChatGPTの"メモリ機能"、使ってない人が9割らしい」 |
| **逆説・意外** | 「AIを毎日使ってる人ほど、実は損してる使い方をしてる」 |
| **共感→気づき** | 「"AIって結局使えない"と思ってた3ヶ月前の自分に教えたいこと」 |
| **小技・裏ワザ** | 「ChatGPTに"小学生に説明して"と付けるだけで、出力が劇的に変わる」 |

## 投稿のトーン

### やること
- **等身大で語る**：「自分はこうだった」「気づいたんだけど」
- **驚きを共有する**：「これマジか」「知らなかった」
- **読者を巻き込む**：「試してみて」「みんなはどう使ってる？」
- **体験ベース**：「○○してみたら→こうなった」
- **断言する**：「これは使った方がいい」「戻れなくなる」

### やらないこと
- 売上・収益・稼ぐ話は一切しない
- 「月○万円」「○万円稼げる」は禁止
- 先生・専門家ポジションで上から語らない
- 「あなたもやるべき」と押し付けない

## 本文の構成ルール

### 基本パターン：気づき→理由→具体例→結論
```
1行目: 発見・気づき（固有名詞+数字のフック）
空行
背景: なぜそうなったか / きっかけ 1〜2行
空行
具体例: 実際に試した内容・結果（数字で示す）
空行
結論: 気づき・学びを1行でまとめる
```

### 文字数
- **推奨: 150〜300文字**
- リスト型は300〜500文字OK

### 改行ルール
- 1文ごとに改行
- 重要ポイントの前に空行
- 箇条書き（①②③）を使う

### 語調
- 自然な口語体。話しかけるように
- 断言する（「〜かも」→「〜だった」「〜変わった」）
- 「僕」「自分」を主語に。読者に「あなた」で語りかける

## ハッシュタグ
- 末尾に2〜3個
- 例: #AI活用 #ChatGPT #Claude #作業効率化 #AI時短 #プロンプト
- 稼ぐ系タグは使わない（#副業 #稼ぐ は禁止）
