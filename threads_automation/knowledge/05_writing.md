# 05 書き方のルール

## 最重要原則：タップ経済

> Threadsがバズるかどうかは**タップ数**と**プロフィールアクセス数**で決まる。
> タップしたくなる投稿を作ることが全て。
> **1行目で決まる。**

## 1行目（フック）のルール

### 必須要素：固有名詞 + 数字
- ❌「AIで副業始めました」
- ✅「ChatGPTで月12万円稼いだ方法を公開する」
- ❌「便利なツールを見つけた」
- ✅「Claude 3.5が文章力で全AIを超えた。比較した結果がこれ」
- ❌「時短できるようになった」
- ✅「Perplexityに変えたら調べものが1日3時間→15分になった」

### 1行目パターン集
| パターン | 例 |
|---------|-----|
| **数字+成果** | 「ChatGPTで月12万稼いだ全手順」 |
| **固有名詞+比較** | 「Claude vs ChatGPT、1000文字書かせたら差が歴然」 |
| **損失回避** | 「AI副業で月5万損してた原因がこれだった」 |
| **逆説** | 「ChatGPTを使うほど文章力が落ちる人の特徴」 |
| **権威+数字** | 「元Google社員が教えるAI活用術3選」 |
| **体験+変化** | 「AIど素人だった僕が90日で月収30万になった話」 |

## 本文の構成ルール

### PREP法（基本）
```
1行目: ベネフィット（フック）
理由: なぜそうなるのか1〜2行
具体例: 実際の体験・数字・固有名詞
結論: 行動喚起 or まとめ
```

### 文字数
- **推奨: 150〜300文字**
- 150文字以下: 情報が薄く保存されにくい
- 300文字超: 最後まで読まれにくい
- 例外: リスト型は300〜500文字でもOK

### 改行ルール
- 1文ごとに改行
- 重要なポイントの前に空行を入れる
- 箇条書き（①②③）を積極活用

### 語調
- 自然な口語体（ですます調OK）
- 断言する（「〜かもしれません」→「〜です」）
- 読者に語りかける（「あなた」「僕」を使う）

## ハッシュタグ
- 末尾に2〜3個
- 必須: #AI活用 または #ChatGPT
- 追加: トピックに合わせて1〜2個
- 例: #副業 #AI副業 #プロンプト #時短 #Claude
