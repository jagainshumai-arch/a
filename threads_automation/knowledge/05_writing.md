# 05 書き方のルール

## 7つの黄金ルール（リーチ爆発の法則）

### ルール1: 質問形式で巻き込む
- 投稿の中に読者への問いかけを入れる
- 「みんなはどう使ってる？」「どっち派？」
- 問いかけ → コメント増加 → アルゴリズム評価UP → リーチ爆発

### ルール2: 投稿タイミングを最適化
- **朝 7:00〜9:00**（通勤中にサクッと読める）
- **昼 12:00〜13:00**（昼休みの関心が高い）
- **夜 20:00〜22:00**（ゆっくり読める時間帯）
- 投稿直後の反応速度がアルゴリズムに影響大

### ルール3: 1行目で止める
- スクロールを止めさせる1行目が全て
- **固有名詞**（ChatGPT/Claude/Perplexity/Gemini）+ **数字**を必ず入れる
- 意外性・ギャップ・具体的変化を1行で表現

### ルール4: 行動喚起（CTA）を入れる
- 「あなたはどう思う？」「試してみて」「どっち使ってる？」
- コメントを促す一言 → エンゲージメント増 → リーチ拡大
- 最後の1行で必ず読者にアクションを求める

### ルール5: 投稿構造を最適化する
- **冒頭**: 意外な事実・発見で注目を集める
- **本文**: 箇条書き・短文で読みやすく
- **結論**: アクションを促す一文で締める
- 1文ごとに改行。空行で区切る

### ルール6: ニッチに絞って毎日投稿
- AI活用の気づき・知見・効率化に特化
- 1日2〜3投稿を継続
- 独自の視点を加えて価値ある情報を提供し続ける

### ルール7: データで改善し続ける
- 伸びた投稿のパターンを分析→再現
- 伸びなかった投稿の失敗要因を特定
- 定期的に勝ち型テンプレートを更新

## 1行目（フック）パターン集

| パターン | 例 |
|---------|-----|
| **発見・驚き** | 「ChatGPTに"逆に反論して"と指示したら、出力の質が別次元になった」 |
| **Before/After** | 「Claudeに議事録を任せたら、2時間の作業が3分で終わった」 |
| **比較・実験** | 「同じ指示をChatGPTとClaudeに出した。差がエグかった」 |
| **知らないと損** | 「ChatGPTの"メモリ機能"、使ってない人が9割らしい」 |
| **逆説・意外** | 「AIを毎日使ってる人ほど、実は損してる使い方をしてる」 |
| **質問型** | 「ChatGPTとClaude、結局どっちがいいのか3ヶ月使い比べた結論」 |
| **小技・裏ワザ** | 「ChatGPTに"小学生に説明して"と付けるだけで、出力が劇的に変わる」 |

## 投稿のトーン

### やること
- **等身大で語る**：「自分はこうだった」「気づいたんだけど」
- **驚きを共有する**：「これマジか」「知らなかった」
- **読者を巻き込む**：「試してみて」「みんなはどう使ってる？」
- **体験ベース**：「○○してみたら→こうなった」
- **断言する**：「これは使った方がいい」「戻れなくなる」

### やらないこと
- 売上・収益・稼ぐ話は一切しない
- 「月○万円」「○万円稼げる」は禁止
- 先生・専門家ポジションで上から語らない
- 「あなたもやるべき」と押し付けない

## 本文の構成ルール

### 基本パターン：気づき→理由→具体例→CTA
```
1行目: 発見・気づき（固有名詞+数字のフック）
空行
背景: なぜそうなったか / きっかけ 1〜2行
空行
具体例: 実際に試した内容・結果（数字で示す）
空行
CTA: 読者への問いかけ or アクション促進
```

### 文字数
- **推奨: 150〜300文字**
- リスト型は300〜500文字OK

### 改行ルール
- 1文ごとに改行
- 重要ポイントの前に空行
- 箇条書き（・や①②③）を使う

### 語調
- 自然な口語体。話しかけるように
- 断言する（「〜かも」→「〜だった」「〜変わった」）
- 「僕」「自分」を主語に。読者に「あなた」で語りかける

## ハッシュタグ：使わない

> **重要: ハッシュタグ（#）は一切使わない。**
> Threadsではタグをつけた瞬間にインプレッションが激減するという実データあり。
> 余計なものをつけず、テキストだけで投稿する。
