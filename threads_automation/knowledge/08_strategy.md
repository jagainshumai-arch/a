# 08 戦略

## 核心：タップ経済を制する

> Threadsのアルゴリズムは**タップ数**と**プロフィールアクセス数**で決まる。
> 投稿を見た人が「タップして続きを読みたい」と思うかどうかが全て。
> **1行目の固有名詞と数字で勝負は決まっている。**

## フェーズ別戦略

### Phase 1: 0〜1000フォロワー（量で学ぶ期間）

**目標**: 投稿パターンの発見、勝ち型の特定
**投稿頻度**: 1日3〜5投稿
**重点**:
- とにかく量を出して反応パターンを掴む
- 7投稿タイプ（発見・驚き/Before・After/比較・実験/知らないと損/逆説・意外/日常の気づき/小技・裏ワザ）を全部試す
- 表示回数1000以上の投稿が出たらその型を分析→テンプレ化
- この段階では完璧を求めない。失敗投稿こそデータの宝庫

### Phase 2: 1000〜5000フォロワー（型を磨く期間）

**目標**: 勝ち型の再現、フォロワーとの信頼構築
**投稿頻度**: 1日2〜3投稿（質を上げる）
**重点**:
- Phase 1で見つけた勝ち型を繰り返す
- テンプレ化した型をAIに入力して量産
- 「この人のAI情報は信頼できる」というポジションを確立
- プロフィールアクセス率を上げるために有益な投稿を継続

### Phase 3: 5000フォロワー〜（影響力拡大期）

**目標**: AI活用の第一想起ポジションを獲得
**投稿頻度**: 1日1〜2投稿（質重視）
**重点**:
- 反応が良いテーマで深掘りシリーズ投稿
- フォロワーからの質問に答える形式の投稿
- 仕組み化（AIで下書き→レビュー→予約投稿）
- 他のAI系アカウントとの相互引用で露出拡大

## 投稿スケジュール

| 時間帯 | 投稿タイプ | 理由 |
|--------|-----------|------|
| 7:00〜8:00 | ノウハウ系・小技型 | 通勤中にサクッと読める |
| 12:00〜13:00 | 発見・Before/After | 昼休みの関心が高い |
| 21:00〜22:00 | 日常の気づき・比較型 | 夜は共感系が伸びる |

## KPI（追跡指標）

| 指標 | 目標値 | 計測方法 |
|------|-------|---------|
| 表示回数/投稿 | 3,000以上 | Threads API insights |
| エンゲージメント率 | 3%以上 | (likes+replies+reposts)/views |
| プロフィールアクセス率 | 5%以上 | アカウントインサイト |
| フォロワー増加/週 | 100人以上 | Threads API |

## AIパイプライン自動化戦略

```
毎日のサイクル:
  朝: /fetcher で前日のインサイト取得
  ↓
  /analyst でパフォーマンス分析
  ↓
  /researcher でトレンド調査
  ↓
  /writer でナレッジ参照して投稿3本生成
  ↓
  /poster でレビュー→投稿公開
  ↓
  夜: /supervisor で1日の振り返り

週次:
  /supervisor で勝ち型テンプレートの更新
  ナレッジファイルの更新（06_references.md）
  低パフォーマンス投稿の分析→NGルール更新
```
