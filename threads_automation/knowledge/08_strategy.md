# 08 戦略

## 核心：タップ経済を制する

> Threadsのアルゴリズムは**タップ数**と**プロフィールアクセス数**で決まる。
> 投稿を見た人が「タップして続きを読みたい」と思うかどうかが全て。
> **1行目の固有名詞と数字で勝負は決まっている。**

## 投稿作成の3大原則

### 原則1: 1行目を5案出して最強の1つを選ぶ
- AIに1行目を1個だけ出させると弱いやつが来る
- 5個出させて「有益そう」「意外性がある」「続きが気になる」で選ぶ
- これだけで投稿の質がかなり変わる

### 原則2: セルフチェックさせる
- AIに「自分でチェックしろ」と言うとちゃんとチェックしてくれる
- チェック項目：
  - □ 1行目で手が止まるか？
  - □ AI感のある表現がないか？（「〜と言えるでしょう」等）
  - □ NGルールに違反してないか？
  - □ 口調・文体がプロフィールに合ってるか？

### 原則3: 本文で完結させない
- コメント欄用の続きも用意する
- 「続きはコメント欄で」→ コメント数が増える → アルゴリズム評価UP
- セルフリプライで補足情報を投稿

## AIパイプライン自動化戦略

### ファイル管理

| ファイル | 役割 | 更新タイミング |
|---------|------|--------------|
| next-topics.md | 次に書くべきテーマ（切り口+1行目案つき） | アナリスト実行時 |
| post-queue.md | 完成した投稿の待ち列 | ライター実行時 |
| post-history.md | 投稿履歴（ID・日時・メトリクス） | ポスター/フェッチャー実行時 |
| analysis-latest.md | 最新の分析結果 | アナリスト実行時 |
| supervisor-report.md | 運用レポート | スーパーバイザー実行時 |

### 毎日のサイクル

```
朝: /fetcher で前日のインサイト取得（投稿から24時間以上経ったもの）
  ↓
/analyst でパフォーマンス分析
  - 伸びた投稿の1行目・構造・テーマの共通点を特定
  - 伸びなかった投稿のダメだった理由を5つの観点で分析
  - 次に書くべきテーマ3つを提案 → next-topics.md に保存
  ↓
/writer でナレッジ参照して投稿3本生成
  - next-topics.md からテーマを選ぶ
  - 06_references.md から構造を選ぶ（丸パクリ禁止、構造だけ真似る）
  - 1行目を5案出して最強の1つを選ぶ
  - セルフチェック → post-queue.md に保存
  ↓
/poster でレビュー → 投稿公開（1回1投稿）
  - 最終チェック → 本文投稿 → セルフリプライ
  - post-history.md に記録
  ↓
夜: /supervisor で1日の振り返り
  - 全ファイル横断チェック
  - 🟢正常 / 🟡注意 / 🔴停止 のステータス判定
  - 次にやるべきことを具体的に出力
```

### 週次
- /supervisor で勝ち型テンプレートの更新
- ナレッジファイルの更新（06_references.md）
- 低パフォーマンス投稿の分析→NGルール更新

## フェーズ別戦略

### Phase 1: 0〜1000フォロワー（量で学ぶ期間）

**目標**: 投稿パターンの発見、勝ち型の特定
**投稿頻度**: 1日3〜5投稿
**重点**:
- とにかく量を出して反応パターンを掴む
- 7投稿タイプを全部試す
- 表示回数1000以上の投稿が出たらその型を分析→テンプレ化
- この段階では完璧を求めない。失敗投稿こそデータの宝庫

### Phase 2: 1000〜5000フォロワー（型を磨く期間）

**目標**: 勝ち型の再現、フォロワーとの信頼構築
**投稿頻度**: 1日2〜3投稿（質を上げる）
**重点**:
- Phase 1で見つけた勝ち型を繰り返す
- 「この人のAI情報は信頼できる」というポジションを確立
- コメント欄での読者とのやり取りを積極的に

### Phase 3: 5000フォロワー〜（影響力拡大期）

**目標**: AI活用の第一想起ポジションを獲得
**投稿頻度**: 1日1〜2投稿（質重視）
**重点**:
- 反応が良いテーマで深掘りシリーズ投稿
- フォロワーからの質問に答える形式の投稿
- 仕組み化（AIで下書き→レビュー→投稿）

## 投稿スケジュール

| 時間帯 | 投稿タイプ | 理由 |
|--------|-----------|------|
| 7:00〜9:00 | ノウハウ系・小技型 | 通勤中にサクッと読める |
| 12:00〜13:00 | 発見・Before/After | 昼休みの関心が高い |
| 20:00〜22:00 | 日常の気づき・比較型 | 夜は共感系が伸びる |

## KPI（追跡指標）

| 指標 | 目標値 | 計測方法 |
|------|-------|---------|
| 表示回数/投稿 | 3,000以上 | Threads API insights |
| エンゲージメント率 | 3%以上 | (likes+replies+reposts)/views |
| プロフィールアクセス率 | 5%以上 | アカウントインサイト |
| フォロワー増加/週 | 100人以上 | Threads API |
