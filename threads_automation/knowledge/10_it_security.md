## 情報セキュリティの最新トレンド（2025-2026）

### 数字で押さえるファクト
- 2025年のサイバーインシデント総数: **750万件以上**
- 2025年上半期のデータ侵害: 8,000件超、**3億4,500万件の個人情報が流出**
- AIを使ったフィッシングメールが **全攻撃の約60%** に到達
- フィッシングメールの **80%以上がAI生成** になった
- ディープフェイク動画: 2023年50万件 → **2025年800万件**（16倍）
- ランサムウェアは全サイバー攻撃の **過半数** を占める
- サプライチェーン攻撃は5年で **4倍** に増加

### ゼロトラスト（Zero Trust Architecture）
- 「何も信用しない、全て検証する」が基本原則
- 従来の「境界防御」（社外=危険、社内=安全）の概念を捨てる
- 2025年時点で企業の **63%が一部または完全導入**
- **81%が今後12ヶ月以内に導入予定**
- 市場規模: 2025年 306億ドル → 2035年 1,447億ドル予測
- 学生向け投稿切り口: 「ファミレスの無料Wi-Fiを信用しない発想=ゼロトラスト」

### AIセキュリティリスク（バズネタの宝庫）

| 攻撃手法 | 何が起こるか | 具体例 |
|---------|-------------|--------|
| **プロンプトインジェクション** | AIに悪意ある指示を紛れ込ませて誤動作 | 2025年の本番AI環境の **73%で発生** |
| **EchoLeak (CVE-2025-32711)** | Microsoft 365 Copilotでゼロクリック情報漏洩 | メール1通読むだけで社内データ流出 |
| **GitHub Copilot RCE (CVSS 9.6)** | コード補完からコード実行へ | CVE-2025-53773で検証済み |
| **RAG Poisoning** | データベースに汚染文書を仕込む | **5つの偽文書で90%の誤回答を引き起こせる** |
| **Memory Poisoning** | エージェントの長期記憶を汚染 | 後続の会話で誤った判断を誘導 |
| **Tool Misuse** | AIに許可されたツールを悪用させる | MCPサーバーの権限濫用 |

### AI攻撃の5つの攻撃面（覚えておくべき）
1. プロンプトインジェクション（直接/間接）
2. メモリ汚染（long-term memory poisoning）
3. ツール乱用（tool misuse）
4. サプライチェーン攻撃（pip install の裏）
5. データ流出（exfiltration via side-channel）

## 量子コンピューティングとポスト量子暗号

### 核心ファクト
- 2024年8月、NISTが **3つのPQC標準を正式リリース**
  - **ML-KEM**（Kyber由来、鍵交換）
  - **ML-DSA**（Dilithium由来、電子署名）
  - **SLH-DSA**（SPHINCS+由来、ハッシュベース署名）
- **HQC**: 2026-2027年に追加KEM標準として確定予定
- NIST IR 8547: **2035年までに量子脆弱アルゴリズム（RSA・ECC）廃止**
- **2027年1月1日**: 米国政府の新規National Security System は全てPQC必須

### Harvest Now, Decrypt Later（今盗み、後で解読）
- 今暗号化されて盗まれたデータは、2030年頃の量子コンピュータで復号可能
- つまり **今日の通信が数年後に丸裸になる**
- 学生向け切り口: 「今撮ったLINEのスクショが2030年にバレる話」

## EU AI Act と日本のAI規制（情報系学生の常識）

### EU AI Act（世界初の包括的AI規制法）
- **2025年2月**: 禁止AI（ソーシャルスコアリング、サブリミナル操作等）施行
- **2025年8月2日**: GPAI（汎用AI）ガバナンス義務発効
- **2026年8月2日**: 高リスクAI規則・透明性義務施行 ← これが本命
- **2027年8月2日**: 完全適用
- 制裁金: **最大3,500万ユーロまたは全世界売上7%**（GDPRより重い）

### 日本のAI推進法
- 2025年5月28日成立、**6月4日施行**
- EU方式（拘束的）ではなく **ガイドライン型（自主規制）**
- AI戦略本部（首相直属）が司令塔
- 初会合: 2025年9月13日
- 日本は「イノベーション優先」路線

### GDPR + AI（情報系なら覚えておく）
- 欧州委員会が「AIデータ処理で正当な利益根拠の拡張」を提案
- 制裁金上限: **2,000万ユーロまたは全世界売上4%**

## OWASP Top 10:2025（Web脆弱性ランキング）

### 2026年1月確定版の変更点
- 分析対象: **175,000件以上の脆弱性**
- 認証失敗のカテゴリ: 「**パスワード単体は重要アプリでは許容不能**」と明言

### 覚えておくべきWebセキュリティ用語
| 用語 | 意味 | 攻撃例 |
|------|------|-------|
| **SQLインジェクション** | SQLを不正注入 | `' OR 1=1 --` |
| **XSS（クロスサイトスクリプティング）** | JSを他ユーザーに実行させる | `<script>alert(1)</script>` |
| **CSRF** | 他サイトから意図しない操作 | フォーム偽装 |
| **SSRF** | サーバーに内部アクセスさせる | クラウドメタデータ窃取 |
| **IDOR** | 他人のリソースIDを直接指定 | `/users/1234` を `/users/1235` に |
| **認証バイパス** | ログインを迂回 | JWT改ざん、セッション固定 |

### Passkey / FIDO2（パスワードレス認証）
- **世界で30億個以上のPasskeyが稼働中**
- 500人以上の企業の **87%が導入済みまたは計画中**
- トップ100サイトの **48%がPasskey対応**
- ログイン成功率: Passkey **93%**（従来パスワード63%）
- ログイン所要時間: 平均 **8.5秒**（従来比73%短縮）
