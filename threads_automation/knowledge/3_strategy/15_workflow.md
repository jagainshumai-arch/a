# 15 運用ワークフロー（事業の心臓部）

> Claude Code × ナレッジで「コンテンツを量産 → 集客 → リスト取得 → 商品販売」の
> エンジンを回すための、日々の運用フロー。1億事業もこの型の繰り返しで作られている。
> （YouTube/X/Threads すべて同じ骨格。媒体が変わっても本質は同じ）

## 全体の流れ

```
リサーチ → テーマ抽出 → 台本/投稿生成 → 形にする → 投稿
────────────────────────────  ────────────
   ここまで全部 Claude の仕事        人間 or 演者
```

上流（リサーチ〜生成）を自動化し、人間は「最終テーマ選択」と「形にする作業」だけに絞る。

## ステップ①：毎朝のリサーチ ＝「需要の答え合わせ」

> バズっている投稿は「世の中の需要の答え」。
> 数百万再生・数万いいねの裏には「今、人が何に反応するか」がすでに証明されている。

- **0からネタを考えない。すでに当たっているものから出発する** → これが外さない理由
- 毎朝、自分のジャンルで伸びているアカウント（フォロワー1万人以上）の新規投稿を集める
- **ジャンルを絞る**：自分の事業に転用できる投稿だけ集める（絞らないと使えない）
- 集めた生データは1アカウント1ファイルで蓄積 → 毎日の判断材料にする

### Threadsの位置づけ（このプロジェクト特有の注意）
- 新ネタ・一次情報は **X のほうが早く落ちている**。鮮度目的ならXを見る
- **Threadsは「バズった構成・型」を研究する用途**に使う（→ `5_buzz/patterns.md`）

## ステップ②：テーマ抽出（候補出しは自動、最終選択は人間）

> テーマ出しまで全自動にすると「伸びない台本」を量産する。
> **「今どのテーマでいくか」の最終判断だけは人間がやる。**

### テーマ選定ロジック
1. バズ投稿から、繰り返し出てくる **名詞・主張** を抜き出す
   - 例: 「Fable5」があちこちでバズ → 「今はFable5が来てる」と判断
2. 似たテーマをグルーピングして集計
3. 次の基準で「伸びる確率が高いテーマ」を上位に残す
   - **合計の再生数・表示数が多い**
   - **同じテーマで10万表示クラスの投稿が複数ある**
4. 自分のジャンルに転用できるテーマだけに絞る

### リサーチャープロンプト（テーマ抽出のひな型）

```
あなたは、SNSのトレンドを分析するリサーチャーです。

【入力】
リサーチで集めた直近のバズ投稿の一覧。
各投稿に「媒体／アカウント名／タイトル(or冒頭文)／再生数・表示数」が入っています。

【やってほしいこと】
1. 各投稿から「その投稿が一番伝えたいテーマ」を短い名詞かフレーズで抜き出す
2. 似たテーマどうしをグルーピングしてまとめる
3. テーマごとに集計する（該当投稿数／合計再生数・表示数／10万表示以上の本数）
4. 次の条件に当てはまるものを「伸びる可能性が高いテーマ」として上位に並べる
   ・合計の再生数・表示数が多い
   ・同じテーマで10万表示以上の投稿が複数ある
5. 私のジャンル（◯◯）の投稿に転用できるテーマだけに絞る

【出力】
伸びそうな順にテーマ候補を10個。各テーマに以下を添える。
・テーマ名
・根拠（該当投稿数／合計表示数／10万超の本数）
・このジャンルでどう料理できそうか（一言）
```

- 出力先はNotion / スプレッドシート / MDファイル / LINE、何でもよい
- 大事なのは出力先ではなく「**自動でリサーチしてテーマ候補まで考えさせる**」こと
- Claudeが拾いきれないネタは、自分がSNSで見て「これいい」と思ったものを足す（ケースバイケース）

## ステップ③：ナレッジによる台本/投稿生成

> AIの台本が薄いのは「何も与えていない」から。ナレッジを食わせれば別物になる。

- 決めたテーマを渡すだけで「うちの読者に刺さる投稿」がそのまま出る状態を作る
- ナレッジに入れるもの：読者像／構成の型／使う・使わない言い回し／過去の当たり外れ／専門知識
- **台本の8割はAIだけで完成**。人が手を入れるのは主にイントロ（新規性・つかみ）だけ
- → 詳細は `14_business_model.md`「AIの精度は99%ナレッジで決まる」

## ステップ④：形にする（人間 or 演者）

- 人間がやるのは「Claudeが生み出したものを形にする作業」だけ
- **「0から生み出す作業」は事業から消す**（属人性・ムラ・退職リスクを排除）
- トップは台本書きでなく、上流（マーケ設計・事業方針・経営判断）に集中する

## このワークフローの本質

> 「誰がやっても、だいたい同じ点数の投稿が出せる」状態を作ること。

- 作業を自動化＋ナレッジ化し、自分がいなくても回る仕組みにする
- ここができないと、いくら「自動化しています」と言っても自分の手が離れず、スケールが止まる
- **作業は自動化して、自分は上流に集中する** —— これが規模を作る本質
