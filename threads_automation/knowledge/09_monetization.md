# 09 収益化・アフィリエイト戦略

## 大前提：Threadsの収益化構造

> **Threadsの投稿内にクリック可能なリンクは貼れない。**
> 全ての収益化は「投稿 → プロフィールアクセス → bioリンク」の導線で成り立つ。

```
投稿を見る → タップして続きを読む → 「この人誰？」とプロフィールを見る
→ bioのリンクをタップ → 収益化ページへ到達
```

**だからこそ「タップ経済」が重要。**
プロフィールアクセス数 = 収益の源泉。

## 収益化手法ベスト5（AI×Threads特化）

### ① プロンプト・テンプレート販売（即日開始可能）

**プラットフォーム**: Brain / note / Tips / Gumroad
**価格帯**: 980円〜4,980円
**月収目安**: 5〜50万円

**具体的な商品例**:
- 「ChatGPTで月5万稼ぐプロンプト集（50個入り）」
- 「Threads投稿を5分で作るAIテンプレート10選」
- 「AI副業スタートキット（プロンプト+手順書PDF）」

**投稿→販売の流れ**:
```
Threads投稿: 「ChatGPTで月12万稼いだ方法」（価値提供）
  ↓ プロフィールアクセス
bio: 「使ったプロンプト50個を無料公開中 → リンク」
  ↓ リンクタップ
LP or note: 無料で10個公開 → 「残り40個は有料版で」
  ↓ 購入
Brain/note: 980〜2,980円で販売
```

### ③ LINE公式/メルマガ → 高単価商品販売

**月収目安**: 10〜100万円+

**仕組み**:
```

  ↓ プロフィールアクセス
```

- 「ChatGPTプロンプト集30選（非公開版）」

**月収目安**: 10〜100万円

## bioリンクの最適化

### リンクツリー構成（推奨）

Lit.link / Linktree / Bento を使って複数リンクを1つにまとめる:

```
🔗 あなたのリンクページ:
├── 🎁 無料プレゼント（LINE登録）  ← 最上部（最重要）
├── 📖 AI副業の始め方ガイド（note）  ← アフィリ or 有料記事
├── 🛒 おすすめAIツールまとめ（ブログ）  ← アフィリリンク付き
├── 📚 おすすめAI書籍（楽天ROOM）  ← 楽天アフィリ
└── 💬 AI活用の無料相談（Googleフォーム）  ← コンサル導線
```

### bio文テンプレート

```
AI×副業で月○万達成 | 元○○
ChatGPT/Claude活用術を毎日発信🔥
↓ AI副業の始め方を無料でまとめました
```

## 投稿→収益化の具体パターン

### パターンA: 直接的な誘導（週1〜2回）
```
ChatGPT無料版だけで月5万稼ぐ方法を3つにまとめた。

全部プロフィールのリンク先に書いた。

実際に使ったプロンプトも全部載せてる。

5分で読めるから、AI副業に興味ある人は見てみて。

#ChatGPT #AI副業
```

### パターンB: 価値提供型（メイン・毎日）
```
Claude 3.5にメルマガを書かせたら開封率が1.5倍になった。

ポイントは「ペルソナを3行で指定する」こと。

「30代・会社員・副業で月5万が目標」
これだけ入れるだけで、文体が激変する。

プロンプトの具体例はプロフに貼ってあるので参考にどうぞ。

#Claude #AI活用 #メルマガ
```

### パターンC: 実績報告型（月1〜2回）
```
Threads×AIを始めて3ヶ月の収益報告。

・プロンプト販売（Brain）: 52,000円
・アフィリエイト（A8）: 38,000円
・楽天ROOM: 12,000円

合計: 102,000円

やったことはAIで毎日3投稿しただけ。

始め方はプロフのリンクにまとめてある。

#AI副業 #収益報告
```

## 注意点

- 投稿の**8割は純粋な価値提供**、**2割は誘導・販売**のバランスを守る
- 毎回「リンク見てね」は逆効果 → 価値提供で信頼を積む
- アフィリの場合は「PR」「広告」の明示が必要な場合あり
- 「確実に稼げます」「月100万保証」→ 景表法違反
- 収益が年20万を超えたら確定申告が必要
